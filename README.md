# Relationship Parody

Це проєкт візуальної новели на Ren'Py. Код сюжету організовано за розділами;
ресурси зберігають наявні розташування, оскільки Ren'Py визначає шляхи до
зображень і медіа на їхній основі.

## Структура проєкту

```
game/
├── core/ # Персонажі, спільні прапорці, позиції та псевдоніми аудіо.
├── story/
│ ├── 00_prologue.rpy # Мітка start і хаб вибору бота.
│ └── chapter_01/ # Окремий файл для кожного маршруту першого розділу.
├── images/ # Зображення, які Ren'Py знаходить автоматично; не перейменовуйте без потреби.
├── audio/ # Звукові ефекти.
├── videos/ # Катсцени.
├── gui.rpy # Конфігурація GUI, згенерована/підтримувана Ren'Py.
├── screens.rpy # Екрани інтерфейсу.
└── options.rpy # Конфігурація гри та збірки.

```


## Додавання сюжетного контенту

1. Розміщуйте спільних персонажів, змінні, трансформації та псевдоніми аудіо в `game/core/`.
2. Додавайте новий розділ у `game/story/chapter_02/`, створюючи окремий файл `.rpy` для кожного маршруту.
3. Починайте кожен файл маршруту з короткого коментаря, що вказує його вхідну мітку.
4. Не змінюйте назви міток після того, як можуть бути створені збереження; для з'єднання маршрутів використовуйте `jump`/`call`.
5. Перед комітом запускайте `renpy . lint` із кореня проєкту.

Згенеровані папки Ren'Py (`game/cache/` і `game/saves/`) залишаються невідстежуваними.
