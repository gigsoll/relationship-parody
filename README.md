Пародія на стосунки

Це проєкт візуальної новели на Ren'Py. Код сюжету організовано за розділами; ресурси зберігають свої наявні розташування, оскільки Ren'Py визначає шляхи до зображень і медіафайлів саме з них.

Структура проєкту
game/
├── core/                 # Персонажі, спільні прапорці, позиції та псевдоніми аудіо.
├── story/
│   ├── 00_prologue.rpy   # Мітка `start` і центр вибору бота.
│   └── chapter_01/       # Окремий файл для кожного маршруту в розділі 1.
├── images/               # Автоматично визначувані зображення Ren'Py; не перейменовуйте без потреби.
├── audio/                # Звукові ефекти.
├── videos/               # Катсцени.
├── gui.rpy               # Конфігурація GUI, створена/підтримувана Ren'Py.
├── screens.rpy           # Екрани інтерфейсу.
└── options.rpy           # Конфігурація гри та збірки.

Додавання сюжетного контенту

Розміщуйте спільних персонажів, змінні, трансформації та псевдоніми аудіо в game/core/.

Додавайте новий розділ як game/story/chapter_02/, створюючи окремий файл .rpy для кожного маршруту.

Починайте кожен файл маршруту з короткого коментаря із зазначенням його початкової мітки.

Після появи можливості створення збережень не змінюйте назви міток; використовуйте jump/call для зв’язування маршрутів.

Перед комітом запускайте renpy . lint із кореневого каталогу проєкту.

Згенеровані папки Ren'Py (game/cache/ і game/saves/) залишаються поза системою відстеження версій.
